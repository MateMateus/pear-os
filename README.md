# Pear OS

Sistema operacional baseado em Linux com visual limpo e moderno: dock, central de apps e tudo que você precisa pro dia a dia.

## Download

Baixe a ISO na página de [Releases](https://github.com/MateMateus/pear-os/releases/latest).

**SHA-256:** `85a136bb6b4f8e95103ce1203c681875e82dbc105a3d67b20bb836159e828fe6`

No PowerShell: `Get-FileHash pear-os.iso` — o resultado tem que ser igual ao código acima.

## Como instalar

1. Baixe a ISO.
2. Grave num pendrive de 8 GB ou mais usando o [Rufus](https://rufus.ie/) ou o [balenaEtcher](https://etcher.balena.io/).
3. Reinicie o computador e entre no menu de boot (geralmente F12, F11 ou Esc).
4. Escolha o pendrive, teste o sistema e clique em instalar.

> Dica: faça backup dos seus arquivos antes de instalar.
